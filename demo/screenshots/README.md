# PRAANJEEV — Application Screenshots

Place the PRAANJEEV application screenshots in this folder.

The screenshots should demonstrate the complete emergency coordination journey, from entering an emergency case to receiving an AI-powered hospital recommendation and coordinating the response.



## Requirements

* Minimum: **3 screenshots**
* Format: **PNG or JPG**
* Screenshots must show the PRAANJEEV application running
* Use real or realistic **simulated/demo emergency data**
* Clearly identify simulated hospital/resource information as demo data where applicable
* Avoid empty states, blank dashboards or placeholder screens
* Screenshots should demonstrate actual implemented functionality
* Do not expose API keys, passwords, tokens or other secrets
* Do not expose unnecessary personal or patient-identifying information

## Suggested Demo Scenario

Use one consistent emergency scenario across the screenshots so judges can understand the complete workflow.

Example:

```text
Patient Age: 45
Location: Anand
Heart Rate: 118 BPM
SpO2: 89%
Blood Pressure: 90/60
Emergency Information: Severe chest pain
```

> This scenario is for demonstration purposes only and must not be presented as a medical diagnosis or real patient case.

## Screenshot Tips

* Use a consistent browser window size for all screenshots.
* Keep the PRAANJEEV interface clearly visible.
* Capture screenshots after the application has loaded actual demo data.
* Highlight important UI elements with arrows or circles when useful.
* Keep text readable at normal viewing size.
* Avoid unnecessary browser tabs or personal information.
* Use the same demo scenario throughout the screenshot sequence.
* Prefer screenshots that demonstrate functionality rather than decorative screens.
